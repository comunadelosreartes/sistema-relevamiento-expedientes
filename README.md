# Sistema de Gestión de Expedientes y Licencias - Comuna de Los Reartes

Sistema web desarrollado con **Streamlit** y **Google Sheets API** para la gestión, seguimiento y trazabilidad de trámites y licencias comunales.

## Requisitos
- Python 3.9+
- Streamlit
- Conexión a Google Sheets (mediante `st.connection("gsheets", type=GSheetsConnection)`)
